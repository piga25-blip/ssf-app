À savoir avant de commencer
  • Le mode réseau fait partie de la version officielle 14.0.0. Il est désactivé par défaut : sans lui, l'application fonctionne comme avant sur un seul PC.
  • Pour une première utilisation du mode réseau, faire l'essai sur un dossier EXERCICE plutôt que sur un vrai secours.
  • Seul le PC principal reçoit l'installation. Les autres postes utilisent simplement leur navigateur (Chrome, Edge, Firefox ou Safari, à jour).
  • Pas encore prévu : modifier le planning au doigt sur tablette (la consultation fonctionne).
  • Notez tout ce qui surprend, même un détail : c'est le but de l'essai.

1. Matériel

  • Un routeur Wi-Fi avec mot de passe (internet inutile), sa batterie ou son alimentation
  • Le PC principal (Windows), branché sur secteur si possible
  • Un à trois autres PC, une tablette ou un téléphone
  • Une clé USB (récupération des données à la fin)
  • Cette fiche imprimée et un stylo

2. Préparation du PC principal (avant le jour J)

  1. Mettre l'application en version 14.0.0 :
    • déjà installée (version 13) : accepter la mise à jour proposée au lancement (connexion internet nécessaire). Les secours déjà enregistrés sont repris automatiquement ;
    • pas encore installée : lancer « SSF-Bootstrap.exe » (ou « Application-SSF-Setup-14.0.0.exe ») et suivre l'installateur jusqu'au bouton Fermer.
    Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires puis Exécuter quand même (le programme n'est pas signé).
  2. Pare-feu : rien à faire à l'avance — l'application demande elle-même l'autorisation quand on active le mode réseau (voir partie 3). À défaut, procédure manuelle en encadré « Pare-feu » ci-dessous.
  3. Ouvrir « Application SSF » (icône sur le bureau) pour vérifier qu'elle démarre. Le titre de la fenêtre indique Version 14.0.0 et le bouton 🌐 Mode réseau est présent.
  4. Régler le PC pour qu'il ne se mette pas en veille quand on ferme le capot (Paramètres › Système › Alimentation). L'application empêche la mise en veille automatique, mais pas celle du capot fermé.

3. Mise en place sur le terrain

  1. Allumer le routeur. Connecter tous les appareils au même Wi-Fi.
  2. PC principal : ouvrir l'application, créer un dossier EXERCICE, choisir PC de Terrain, indiquer le secrétaire.
  3. Cliquer sur 🌐 Mode réseau puis Activer le mode réseau.
    L'application vérifie le pare-feu et l'autorise elle-même si besoin. L'ordinateur peut demander confirmation : Windows : « Voulez-vous autoriser cette application à apporter des modifications… » → Oui ; Mac : mot de passe de l'ordinateur → OK.
    Si Windows affiche aussi « Alerte de sécurité Windows » : cocher réseaux privés et réseaux publics, puis Autoriser l'accès.
    La fenêtre « Mode réseau » doit afficher « 🛡️ Pare-feu … : les autres postes sont autorisés » (ou « désactivé : rien à régler »). Sinon : bouton 🛡️ Autoriser dans le pare-feu, ou procédure manuelle ci-dessous.
  4. Recopier ici l'adresse et le code affichés :
    Adresse (http://…:8080) :
    Code de session :
  5. Cocher Autoriser la saisie sur les autres postes.
🛡️ Pare-feu — procédure manuelle (seulement si l'application n'a pas pu l'autoriser elle-même, ou si un autre poste reste sans réponse : « Ce site est inaccessible »)

Windows — méthode rapide : dans le dossier du kit, double-cliquer sur « autoriser-pare-feu.cmd » (« Windows a protégé votre ordinateur » : Informations complémentaires › Exécuter quand même), répondre Oui ; le message « OK : les autres postes peuvent se connecter à ce PC » s'affiche.

Windows — sans le script :

  1. Menu Démarrer : taper « pare-feu » et ouvrir « Pare-feu Windows Defender avec fonctions avancées de sécurité ».
  2. À gauche : Règles de trafic entrant ; à droite : Nouvelle règle…
  3. Type de règle : Port › Suivant.
  4. TCP ; Ports locaux spécifiques : 8080-8089 › Suivant.
  5. Autoriser la connexion › Suivant.
  6. Cocher Domaine, Privé et Public › Suivant.
  7. Nom : Application SSF › Terminer.

Mac : menu Pomme › Réglages Système › Réseau › Coupe-feu. Si le coupe-feu est désactivé : rien à faire. S'il est activé : Options… › bouton + › choisir Application SSF dans le dossier Applications › régler sur « Autoriser les connexions entrantes » › OK. Si le Mac demande « Voulez-vous que l'application … accepte les connexions réseau entrantes ? » : Autoriser.

4. Connexion des autres postes

  • PC : ouvrir le navigateur (Chrome, Edge, Firefox…) et taper l'adresse ci-dessus en entier, avec http:// (ex. http://192.168.1.26:8080) dans la barre d'adresse, tout en haut de la fenêtre ; saisir le code de session, puis donner le nom du secrétaire quand il est demandé.
  • Tablette ou téléphone : scanner le code QR affiché dans « 🌐 Mode réseau » sur le PC principal avec l'appareil photo (le code de session est déjà dedans). C'est le plus simple. À défaut, taper l'adresse comme sur un PC : dans la barre d'adresse du navigateur, avec http://.
  • ⚠️ Ne pas taper l'adresse dans une recherche Google (application Google, barre de recherche de l'écran d'accueil, page google.fr) : on obtient une page de résultats au lieu de l'application. Sans http:// au début, certains navigateurs lancent aussi une recherche.
  • Sur le PC principal, la fenêtre 🌐 Mode réseau liste les postes connectés. Régler chacun en Saisie ou Consultation.
  • Sur chaque autre poste, le bandeau doit indiquer « 🟢 Connecté au poste principal ».

7. Fin de l'essai : récupérer les données

  1. PC principal : 💾 Exporter Tout (fichier à garder).
  2. 🌐 Mode réseau › Désactiver, puis fermer l'application.
  3. Copier sur la clé USB le dossier suivant (taper le chemin dans la barre de l'Explorateur) :
    %APPDATA%\Application SSF\secours
    Il contient un dossier par secours, avec le journal de toutes les actions (qui, quoi, quand), utile pour analyser l'essai. Il suffit de copier le dossier de l'exercice de l'essai (son nom reprend celui du secours).
  4. Transmettre la clé, le fichier exporté et cette fiche remplie.

9. Après l'essai

  • L'application reste installée telle quelle : c'est la version officielle. Le mode réseau peut rester désactivé jusqu'au prochain usage.
  • L'autorisation du pare-feu peut rester en place (elle ne sert que lorsque le mode réseau est activé). Pour la retirer quand même : double-clic sur « retirer-pare-feu.cmd », puis Oui ; elle sera redemandée à la prochaine activation.
  • Si l'ancienne version de test « Application SSF Reseau (test) » est encore installée sur ce PC, elle peut être désinstallée (Paramètres › Applications) ; « retirer-pare-feu.cmd » retire aussi sa règle de pare-feu.
En cas de problème de connexion
  • Une page de résultats de recherche s'affiche au lieu de l'application : l'adresse a été tapée dans une recherche Google ou sans http://. La retaper en entier, avec http://, dans la barre d'adresse du navigateur — ou scanner le code QR.
  • Le poste n'arrive pas à ouvrir l'adresse (« Ce site est inaccessible ») : vérifier qu'il est sur le même Wi-Fi (pas le Wi-Fi invité de la box, pas la 4G) ; vérifier sur le PC principal que la fenêtre 🌐 Mode réseau affiche « 🛡️ Pare-feu … autorisés », sinon 🛡️ Autoriser dans le pare-feu ou l'encadré « Pare-feu » ; vérifier l'adresse dans 🌐 Mode réseau.
  • Plusieurs adresses affichées (PC avec câble et Wi-Fi) : essayer celle qui commence comme l'adresse Wi-Fi du poste (souvent 192.168.…).
  • « Code incorrect » : reprendre le code affiché actuellement sur le PC principal (il change avec « Changer le code »).
